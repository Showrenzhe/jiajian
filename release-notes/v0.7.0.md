## 工作台布局

- 素材库、播放器、混剪设置和时间线共用一套分区。拖面板之间的空隙可调宽高，拖交点可同时调两个方向。
- 想多看一点画面时，向外拖播放器左边或右边的小箭头，该侧面板会移到下排。想给侧栏更多高度时，向内拖时间线同侧的箭头，侧栏会占满这一列。反向拖动可还原，也可以点箭头切换。
- 调换面板位置后，新位置的边缘仍可调整。点「完成布局」保留修改，按 Esc 可撤销本轮布局调整。

## 分镜顺序

- 在时间线的紫色「分镜」行，按住一段分镜左右拖动。插入线标出松手后的位置，可以移到最前、最后或任意两个分镜之间。拖到时间线左右边缘会自动滚动。
- 选中分镜后，按 Alt + ← 或 Alt + → 可前移或后移一位。拖动中按 Esc 可取消。分镜的候选画面、分段口播和对应的分段脚本一起移动。

## 弹窗动效

- 点击「包装轨道」时，编辑面板从按钮方向轻轻展开，背景遮罩同步淡入。打开「调整关键帧」后，按 Esc 会先收起这一层，并把焦点送回原按钮。
- 设置、软件更新及其他编辑弹窗使用统一的打开和收起动效。开启系统「减少动态效果」时直接切换。

## 导航与编辑反馈

- 从剪辑台打开「编辑脚本」，完成后可直接回到原工程继续剪辑。从首页打开本地工具再返回，键盘焦点会回到原入口。快速切换业务页时，较早发出的请求不会把页面切回去。
- 在素材库或时间线上拉框选择时，按 Esc 恢复原来的选区。拖动字幕或悬浮播放器时，按 Esc 可还原位置。在悬浮播放器内再按 Esc 可将它放回工作台。检查器里的折叠设置沿用弹窗内的展开和收起动效。
- 配音音色的筛选条件会立即标出，列表会区分加载中、无结果和失败。音频处理取消后会提示正在收尾。用键盘检查更新或开始下载时，焦点会留在更新弹窗的可用控件上。

## 从上一个公开版本升级

- 首页右侧集中显示本地创作入口，设置中可选择浅色、深色或跟随系统。素材库支持文件夹图标、右键和 Delete 移除，磁盘原件保留。按住 Ctrl 滚动可缩放素材缩略图或时间线。
- v0.6.2 离线 ZIP 用户请先下载并运行本次 Windows x64 安装包。有手动保存的工程可直接打开，自动草稿和设置的迁移步骤见仓库 README。安装版以后可从右上角「软件更新」查看说明、下载并保存重启。需要卸载时，可在 Windows 已安装的应用中选择「佳剪」。
- 如果「软件更新」中显示当前版本为误标的 7.0.0，请保存工程、退出佳剪，再手动运行本次 0.7.0 安装包覆盖安装。重新打开后可在标题栏核对版本号。
