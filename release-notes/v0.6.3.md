## 剪辑台

- 首页右侧集中显示「本地创作」的五个入口。左侧栏直接列出视频制作、素材生产、矩阵分发和管理工具。
- 素材库的「导入文件」「添加文件夹」「音频处理」改为浮起的圆角按钮，面板变窄时会自动换行。首页、侧栏和素材工具栏统一使用单色线形图标。
- 修复了空素材库点击「音频处理」时报错的问题，可直接选择多个音频文件。
- 在设置中可选择浅色、深色或跟随 Windows 系统外观。面板和控件按同一节奏过渡，快速切回时从当前亮度继续。开启系统的「减少动态效果」后直接切换。
- 修复了深色外观下展开「画幅」「分辨率」等下拉菜单时，未选中的选项文字难以辨认的问题。
- 素材库用文件夹图标显示导入的目录。可通过右键菜单或 Delete 移除选中的素材和文件夹，保留磁盘原件和已加入时间线的片段。
- 留边背景、字幕等颜色设置改用圆形色轮，支持拖动选色、调整饱和度和亮度，以及输入精确色值。
- 素材库、播放器、混剪设置和时间线分成四块独立面板。面板间隙在鼠标悬停和拖动时均隐藏中线。直接拖动间隙可调整大小，按 Esc 取消。侧栏支持收起和展开。
- 按住 Ctrl 滚动鼠标滚轮，可在时间线调整缩放，也可调整素材库缩略图大小。

## 安装与更新

- 首次使用 Windows x64 安装版，或从 v0.6.2 离线 ZIP 迁移，请从 GitHub 正式版页面下载并运行 Jiajian-Setup-0.6.3-x64.exe。已有离线工程可用「工程管理」打开。
- 安装版在启动时和持续运行期间每四小时检查新版本。首页和剪辑台的标题栏都可直接打开「设置」左侧的「软件更新」。发现新版或下载就绪时，提醒会显示在该按钮上。
- 点「软件更新」可查看本次改动、下载新版本，并在方便的时候保存草稿并重启安装。收起提醒后，按钮仍可使用。
- 开始菜单新增「卸载佳剪」。也可在「软件更新」中点「在 Windows 中卸载…」打开系统应用列表。卸载后会保留本地草稿和设置，重新安装可继续使用。
