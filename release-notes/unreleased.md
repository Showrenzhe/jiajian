# 未发布

- 设置 FFmpeg 和 FFprobe 路径时优先使用 `JIAJIAN_FFMPEG` 和 `JIAJIAN_FFPROBE`。旧设置仍有效，使用时会收到一次迁移提示。
- 已有媒体工具通过校验后可直接离线构建。从需要授权的来源下载工具时，错误提示会隐藏令牌和签名参数。
- 更新合并前，会在同一台机器上反复测量时间线拖动、缩放等操作，检查新版本是否出现更多延迟。
- 更新合并前，负责人会核对自动检查结果，以及本次改动涉及的旧工程兼容性和界面验证记录。
- 内部集显性能采样默认关闭，管理员可按需启用并从默认分支手动运行。
- 固定自动测试和发布流程所用工具的版本。工具和 npm 依赖有新版时，每周集中提交更新供核对。
- [Windows 发布指南](../docs/windows-release.md#当前分发渠道)列出了自动与手动检查更新的方法，并说明已装内部离线版 0.9.0 的用户如何覆盖安装一次、继续使用原草稿。
