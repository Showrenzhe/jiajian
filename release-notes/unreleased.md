# 未发布

- 混剪默认复用上次成功的种子。「换一批」会重新选取组合，配乐也计入组合数。可让每条成片都有指定分镜候选，并控制镜头重复程度。[随机组合与种子](../docs/manual.md#随机组合与种子)

- 新工程默认在口播期间将配乐降低 9 dB，口播结束后用 300 ms 恢复。配乐实际循环时，接缝默认交叉淡化 200 ms。整片响度归一默认关闭，开启后按每条成片分别测量。[配乐设置](../docs/manual.md#配乐与成片响度)

- 在「口播」的「成片设置」中展开「口播裁剪」，可以设置静音阈值、最短静音、接缝保留和硬切淡出。画面优先时，智能裁剪会依次寻找句末和停顿，找不到时在画面截止处淡出。时间线的「已裁短」标记可查看首尾各裁掉多少秒。[口播设置](../docs/voice.md#决定画面和口播的长度)
- 旧工程和草稿打开后沿用旧规则，首次覆盖保存为 v7 时，同目录会留下 `原名.pre-v7.jiajian` 或 `原名.pre-v7.sdworkbench`。不支持硬链接的卷使用 `原文件名.pre-v7/原文件名`。已有的旧版备份可继续打开。[备份与恢复](../docs/time-model.md#旧工程备份与恢复)

- 在主时间线按 M 添加标记点，可命名、跳转或删除。标记点按工程起点后的秒数保存，移动分镜或改变帧率后仍位于同一时间。拖动时亮线会指示吸附位置，按住 Alt 可临时关闭吸附。
- 把播放头移到审片起止位置，分别按 I、O，再从「编辑工具」开启循环。Alt+I、Alt+O 可分别清除两端。按 J、L 向后或向前审片，连按可切换 2×、4×、8×，按 K 暂停。倒放时静音。

- 按 Ctrl+K 或点击标题栏的「命令面板」，即可搜索命令、最近工程和设置。选中视频片段后，加文字、加贴纸、静音和倍速会优先出现。

- 首页可直接进入视频混剪和工程管理，草稿封面标出时长、分镜数与最近编辑时间。播放时控件自动淡出，拖动播放头显示时间码与帧号，删除时间线片段后可直接撤销。

- 可在「设置」的「外观」中选择完整、精简或关闭玻璃效果。软件渲染兼容模式会自动关闭玻璃效果，恢复硬件渲染后会沿用之前的选择。
- 可在设置中调整自动对齐的倍速范围，在片段属性中手动锁定速度。
- 自动检查会用同一个样片工程对比预览与导出成片，核对倍速画面、转场、字幕出现时刻和音量。
- 手机拍摄的可变帧率视频在代理预览中按工程帧率播放，竖拍照片按正确宽高导入。HDR 视频默认转为 BT.709 SDR，可在设置的「性能与代理」中选择保留 HDR。
- 连续拼接变速或裁剪过的短镜头时，生成预览和导出按整条成片分配画面帧数。口播字幕的起止点也会限制在对应的音频区间内。
- 批量预览里可用上下方向键逐条切换勾选框或播放按钮。搜索或排序后，方向键按屏幕上的顺序移动，按 Ctrl+A 可选中全部筛选结果。
- 点选或双击视频轨片段时可以轻微移动鼠标。移动超过 5 像素才开始拖拽，半透明片段会跟随指针。按 Esc 可回到原位，并保留已有的撤销和重做记录。
- 在时间线上右键点口播、音乐或音效，可以调整倍速、删除片段或将整条轨道静音。包装片段也能右键删除，画中画和贴纸保留分割、编辑入口。
- 设置 FFmpeg 和 FFprobe 路径时优先使用 `JIAJIAN_FFMPEG` 和 `JIAJIAN_FFPROBE`。旧设置仍有效，使用时会收到一次迁移提示。
- 已有媒体工具通过校验后可直接离线构建。从需要授权的来源下载工具时，错误提示会隐藏令牌和签名参数。
- 更新合并前，会在同一台机器上反复测量时间线拖动、缩放等操作，检查新版本是否出现更多延迟。
- 更新合并前，负责人会核对自动检查结果，以及本次改动涉及的旧工程兼容性和界面验证记录。
- 内部集显性能采样默认关闭，管理员可按需启用并从默认分支手动运行。
- 固定自动测试和发布流程所用工具的版本。工具和 npm 依赖有新版时，每周集中提交更新供核对。
- [Windows 发布指南](../docs/windows-release.md#当前分发渠道)列出了自动与手动检查更新的方法，并说明已装内部离线版 0.9.0 的用户如何覆盖安装一次、继续使用原草稿。
