# 佳剪使用手册

## 素材、分镜和片段

素材是库中的源文件。把素材放进分镜后，就成为该分镜可选用的候选。时间线上的片段记录入出点、速度、静音和位置。同一素材可以出现在多个片段中。紫色分镜条代表一整镜，移动分镜时，它的候选和分段口播一起移动。[完整术语表](terminology.md)

在素材库点「导入素材」，可选择文件或整个文件夹。点「新建文件夹」可在当前目录整理素材，右键文件夹可重命名或移除。文件夹层级随工程保存，创建、改名和移除也会同步到本地草稿目录。可勾选多项素材，再拖动任一已选项或点「添加所选」，将整批加入同一个分镜。拖到「新建分镜」区域会为整批创建一组分镜。素材旁的「＋」可单独添加。

从 Windows 文件资源管理器可将 SMB 共享中的视频、图片、音频或整个文件夹拖入素材库，重开草稿时需能访问原共享路径或映射盘符。

从素材库移除已用视频前，确认框会列出当前工程受影响的视频片段数。确认后会同时移除这些实例，磁盘原文件保留。按 Ctrl+Z 可一并恢复素材和片段。

## 画面与时间线

单击候选预览，双击视频进入片段剪辑。在胶片下方展开数值输入，使用 hh:mm:ss.ff 或从 0 开始的帧号设置入点、出点和时长。确认画面后点「应用裁剪」。

拖动时间尺或竖线上的播放头可查看对应画面，拖动轨道下边缘可调高度。折叠后仍会显示整条素材的位置。左键从轨道空白处拉框可多选素材。分镜候选会标出播放时长，素材库中的已用标记会随工程编辑更新。

时间线上可直接看到口播、配乐、音效和视频原声的波形。将播放头拖到要试听的位置，按空格开始播放，再按一次暂停。

右键视频片段，选择「静音片段」可关闭它的原声。同一素材放在其他位置仍可单独调节，配乐和口播继续播放。再次右键选择「取消静音」会恢复原先的音量。要听见原声，还需开启「保留视频原声」并取消整轨静音。

「适应」填充支持设置纯色留边。分镜的「到下一分镜」可选淡黑或淡白，转场在相邻两段各自内部淡出、淡入，保持成片总时长。每条成片从每组取一条候选，从配乐库随机取一首并按需循环。配乐可从成片开头或指定分镜开始，乱序时仍跟随该分镜。

从分镜条的把手拖动整镜，在插入线处松手，或按 Alt + 方向键移动已选分镜。拖动过程中按 Esc 可取消。

## 布局与包装

混剪页按素材库、播放器、混剪设置和时间线组织。直接拖相邻面板的分隔边可调宽高，拖交点可同时调整两个方向。向下拖素材库或混剪设置的底边，该面板会占满一列。向外拖播放器侧边的小箭头，同侧面板会移到下排，为播放器让出宽度。向内拖时间线侧边的小箭头，会给同侧面板腾出一整列。反向拖动可还原，也可点箭头切换。

在顶部可选「剪辑优先」「口播优先」「预览优先」三套本机布局。布局是本机偏好，各工程共用。在「调整布局」中拖动面板把手交换位置，点「完成布局」退出。按 Esc 撤销本次调整。需要更大抓取区域时，可在「调整布局」选择「面板尺寸」；也可从「编辑工具」打开「调整轨高与面板尺寸」，直接设置轨道高度。

需要给候选添加文字、贴纸、画中画或音效时，选中视频，再打开「编辑工具」中的候选操作。双击已有包装片段可继续编辑。

## 口播、字幕与脚本

从「脚本创作」可编辑整段口播、分段口播或文字组，每行支持台词和参考画面备注。可批量粘贴文本，用 Tab 分开内容和备注。脚本草稿自动保存在本机，点击「前往混剪」后可在工程内查看和继续编辑脚本。

点击「批量导入 SRT」可多选文件。第 1 轨的字幕位置为空时先填入第一份有效字幕，其余字幕各自新增一轨，已有内容保留。无法导入的文件会提示原因，成功项仍会添加。单个 SRT 文件上限为 256 KiB，单批字幕内容另有总量上限。

打开「混剪设置 → 字幕」，可从字形方块直接比较和选择预设。选中后可以继续调字色、字重、描边、间距和画面位置，再保存为自己的预设。点「放大预览」后可直接拖动字幕定位。「导出时显示字幕」统一控制视频识别、口播和 SRT 字幕，切换后工程内仍可编辑这些字幕。

整段和分段的已导入口播都可点「试听／字幕」播放原音频。在弹窗中可填写台词，或采用已关联脚本预填的台词，然后点「应用台词字幕」。字幕覆盖该口播在成片中实际保留的播放区间。整段轨同时有手动导入的 SRT 时，优先使用 SRT。

语音生成、时间对齐和同轨号匹配见[口播与配音设置](voice.md)。

## 预览与导出

剪辑台顶部显示「准备素材」「口播字幕」「生成预览」「勾选导出」四步。点击「生成预览」后，佳剪为本批次确定候选组合。先播放检查画面、口播和切点，再勾选需要的条目并点「导出已选」。清单可以搜索、筛选、排序及反选。每行显示预计时长和大小，实际体积取决于画面内容。导出时显示当前条目与预计剩余时间。批次可取消，已完成的 MP4 会保留。

每批最多可生成 1,000 条。每个分镜最多放 100 个原始候选，整段口播可配置 250 条轨道。

## 继续编辑

首页「最近草稿」可继续上次的编辑。用「保存工程」将工程另存为文件。工程记录素材路径，搬到另一台电脑时需一并保留源文件。[迁移与重新定位](migration.md)
