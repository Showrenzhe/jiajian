# 升级、移动工程与回退

## 打开旧草稿

安装版沿用 `%APPDATA%\佳剪\run-data`。升级前退出佳剪，备份这个目录及重要工程。重新启动后从首页「最近草稿」打开。单独保存的旧 `.sdworkbench` 也可从「打开工程」进入。新建工程默认使用 `.jiajian`。希望兼顾旧机器时，保留旧工程副本。

## 换电脑或素材目录

复制工程、它旁边的素材库文件夹及源视频、口播和配乐。共享盘上的路径需由当前 Windows 账户访问。打开工程后，根据缺失列表选择素材所在的新目录。佳剪会搜索子目录，用已有的文件名、大小和时长信息匹配；同名文件无法区分时，请选择范围更小的文件夹。素材离线时仍可保存工作，再定位后导出。

## 从离线 ZIP 迁移

1. 在同一个 Windows 账户中退出两个版本。备份旧程序旁的 `run-data` 以及安装版的 `%APPDATA%\佳剪\run-data`。两边已有工程时，先分别另存需要保留的工程。
2. 给安装版已有的目录改名留存，将旧版整个 `run-data` 复制到 `%APPDATA%\佳剪\`。保留旧程序目录中的生成口播与预览素材。
3. 从开始菜单启动佳剪，依次检查草稿、素材与配音设置。换 Windows 账户时可重新填写云端配音密钥。

## 更新与回退

团队配置内部更新服务后，安装版默认检查稳定通道，间隔 24 小时。可在设置中切换通道或改为手动检查。收到新版提示后可自行选择下载、保存草稿并重启。离线安装可直接运行团队提供的安装包。

如需回退，退出佳剪，保留当前资料的副本，运行团队保留的上一版安装包，再用升级前备份的工程核对画面和口播。回退到 0.8.0 时，旧版会拒绝部分新版自动生成的极端倍速，涉及这些片段的工程应在支持该速度的版本中编辑。
