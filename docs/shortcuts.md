# 快捷键速查

按 `Ctrl+K` 或点击标题栏的「命令面板」搜索命令、最近工程和设置。按 `?` 或 `Ctrl+/` 查看当前键位。下表列出默认设置。

| 使用位置 | 操作 | 默认键位 |
| --- | --- | --- |
| 全应用 | 命令面板 | Ctrl+K |
| 全应用 | 剪辑帮助 | ? / Ctrl+/ |
| 全应用 | 取消拖动或关闭菜单 | Esc |
| 全应用 | 切换侧栏 | Ctrl+\ |
| 剪辑台与脚本创作 | 批量编辑文字 | Ctrl+F |
| 剪辑台 | 快速保存 | Ctrl+S |
| 剪辑台 | 播放或暂停时间线 | 空格 |
| 剪辑台 | 向左移动分镜 | Alt+← |
| 剪辑台 | 向右移动分镜 | Alt+→ |
| 剪辑台 | 编辑片段 | 双击视频片段 |
| 剪辑台 | 删除 | Delete |
| 剪辑台 | 撤销 | Ctrl+Z |
| 剪辑台 | 重做 | Ctrl+Y / Ctrl+Shift+Z / Ctrl+Shift+Y |
| 时间线 | 复制 | Ctrl+C |
| 时间线 | 粘贴 | Ctrl+V |
| 片段裁剪 | 撤销 | Ctrl+Z |
| 片段裁剪 | 重做 | Ctrl+Shift+Z |
| 片段裁剪 | 分割 | W / Ctrl+B |
| 片段裁剪 | 剪掉左侧 | Q |
| 片段裁剪 | 剪掉右侧 | E |
| 片段裁剪 | 倒放 | 未绑定 |
| 片段裁剪 | 镜像 | 未绑定 |
| 片段裁剪 | 裁剪画面 | 未绑定 |
| 片段裁剪 | 旋转 | 未绑定 |
| 片段裁剪 | 前一帧 | , |
| 片段裁剪 | 后一帧 | . |
| 片段裁剪 | 后退十帧 | Shift+, |
| 片段裁剪 | 前进十帧 | Shift+. |
| 素材库 | 选择素材 | 方向键 / Home / End |
| 素材库 | 打开素材菜单 | Shift+F10 |
| 素材库 | 重命名文件夹 | F2 |
| 素材库 | 从素材库移除 | Delete |
| 视频片段菜单 | 静音片段 | M |
| 视频片段菜单 | 向左插入空分镜 | [ |
| 视频片段菜单 | 向右插入空分镜 | ] |

在标题栏打开「快捷键」可调整片段裁剪和快速保存的按键。设置会提示同一作用范围内的冲突。先前已绑定的 Ctrl+K 在原操作位置继续生效，其他位置仍可用它打开命令面板。

逐帧步进遵循当前剪辑帧率，时间码末两位为帧号。在裁剪页点击「应用裁剪」将当前修改写入工程。
