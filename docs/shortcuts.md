# 快捷键速查

在剪辑台按 `?` 或 `Ctrl+/` 查看当前生效的键位。「设置 → 快捷键」可自定义片段剪辑按键，遇到占用时会提示冲突。下表是默认值。

| 操作 | 默认键位 |
| --- | --- |
| 保存草稿及已绑定的工程 | Ctrl+S |
| 播放或暂停时间线 | 空格 |
| 撤销、重做 | Ctrl+Z、Ctrl+Shift+Z |
| 移动选中的分镜 | Alt+←、Alt+→ |
| 在裁剪页分割 | W 或 Ctrl+B |
| 剪掉播放头左侧、右侧 | Q、E |
| 后退、前进一帧 | 逗号、句号 |
| 后退、前进十帧 | Shift+逗号、Shift+句号 |
| 取消拖动或返回上一层 | Esc |

双击视频片段进入裁剪。逐帧步进遵循当前剪辑帧率，时间码末两位为帧号。在裁剪页点「应用裁剪」将当前修改写入工程。
