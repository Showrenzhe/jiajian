# 佳剪术语

| 名称 | 在佳剪中的含义 |
| --- | --- |
| 素材 | 导入素材库的原视频、音频或图片。 |
| 片段 | 时间线上可选择、移动和裁切的一段内容。 |
| 候选 | 放进某个分镜、参与组合选择的画面片段。 |
| 分镜 | 一组表达同一镜头意图的候选，可绑定口播、字幕和包装。 |
| 分镜条 | 时间线上表示分镜范围的横条。 |
| 口播 | 成片使用的讲解或对白音轨。 |
| 配音 | 从台词录制或合成口播音频的操作。 |
| 整段式口播 | 一条口播轨覆盖多个分镜。 |
| 分段式口播 | 按分镜安排相应口播片段。 |
| 生成预览 | 按当前素材和参数生成可勾选、可播放的成片组合。 |
| 导出已选 | 把勾选的预览组合写成成片文件。 |

混剪步骤依次是准备素材、口播字幕、生成预览、勾选导出。无需口播和字幕时，可以直接生成预览。
