# 佳剪云端创作接口

在「设置 → 云端创作服务」填写服务根地址和可选的 API Key。服务根地址可包含路径。正式服务使用 HTTPS，本机联调可用 `http://127.0.0.1:端口`。提供 Key 后，佳剪发送 `Authorization: Bearer <key>`。密钥保存在本机加密存储。

以下路径均相对于根地址。请求方法为 `POST`，请求体为 `multipart/form-data`。每次请求带 `ratio`（`9:16`、`16:9` 或 `1:1`）和 `prompt`（创作描述，可空）。用户点击生成后才上传所选文件。当前支持一次请求内返回结果，最长十分钟。

| 路径 | 额外字段 | 成功响应 |
| --- | --- | --- |
| `avatar` | `portrait` 图片或视频文件，`voice` 口播音频文件 | 返回含画面的 MP4、WebM 或 MOV 媒体字节，佳剪将其加入新分镜。 |
| `cover` | 可选 `reference` 图片或视频。图片、视频与描述至少提供一项。 | 返回 PNG、JPEG 或 WebP 媒体字节，佳剪将其加入当前工程的封面库。 |
| `replicate` | 本地视频文件 `reference`，或由服务解析的 HTTPS 链接 `reference_url` | 返回下述 JSON，分镜时间单位为秒。 |

媒体响应须使用正确的 `Content-Type`。单个上传文件与视频结果上限为 512 MiB，封面上限为 32 MiB。客户端支持上述视频/图片 MIME，校验并解码返回的文件。出错时请使用相应 HTTP 状态码。

```json
{
  "title": "产品展示",
  "shots": [
    { "name": "产品特写", "start": 0.0, "end": 1.5, "description": "在桌面上展示产品", "dialogue": "先看看外观。" }
  ]
}
```

分镜可以使用不同的原片范围。每段至少 0.1 秒，结束时间须落在原片范围内。每次可返回 1–1000 个分镜。平台链接任务还须在顶层返回 `source_url`，指向同一服务来源的原片，客户端会下载并校验成片。接口服务负责平台链接解析、模型选择和生成。佳剪会保存已生成的本地素材和工程轨道，继续编辑既有结果时可离线使用。
