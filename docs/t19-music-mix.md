# T19 配乐闪避与响度归一

在「混剪设置 → 配乐」中可设置口播出现时的压低幅度，并选择整条成片的目标响度。设置随工程及草稿保存。

| 设置 | 新工程默认值 | 可调整范围 |
| --- | --- | --- |
| 口播时压低配乐 | 降低 9 dB，口播结束后用 300 ms 回到原音量 | 可关闭，降低 6–12 dB，恢复 200–400 ms |
| 配乐循环接缝 | 曲尾与下一遍曲头交叉淡化 200 ms | 100–300 ms，仅在需要续播时生效 |
| 成片响度归一 | 关闭 | −14 或 −16 LUFS，默认真峰值上限 −1 dBTP |

**口播与配乐如何衔接。** 每个组合沿用 T18 裁剪后的实际播放区间，计入整段或分段口播的偏移、倍速、独听、禁用、静音及零音量。按可听区间合并生成一条配乐音量曲线，句末提前收声时即开始恢复，下一段接入时从当时音量平滑压低。配乐从所选分镜起播。按倍速后的曲长安排接缝，重叠最多半个循环，播放到成片末尾即止。极短曲目使用可重复的短循环缓存，限制内存。

**曲目音量。** 导入已授权配乐时在后台测一次综合响度和真峰值，按文件指纹、音频流及算法版本缓存，共享文件读取前复查授权。随机配乐以 −18 LUFS 为参考，补偿量取「参考值减实测值」，限于 ±12 dB，提升后曲目真峰值最多 −1 dBTP。先补偿，再应用用户音量及口播闪避。手动指定配乐默认保留原音量，可选择相同补偿。全静音、音频过短或测量失败时保留曲目音量，并在配乐设置中说明原因。更换文件后重测。

**试听与导出。** 实时试听按同一曲线、接缝与播放位置调度配乐，拖动后从对应位置恢复。需要听成片时可选「成片试听」，播放当前组合经完整导出链路处理的生成预览，能听到响度归一的效果。预览与「导出已选」沿用同一份已选曲目、补偿值及混音计划，更改设置后刷新预览。开启归一时，每条独立用 FFmpeg `loudnorm` 先测整条混音、再按实测值处理，含封面和最终编码的文件再测响度与峰值。全静音保留静音。短到无法测得有效响度时仅校验真峰值并提示；可测成片超标时调整增益重试一次，仍超标则提示实测值并保留重试入口。

**工程兼容。** 工程格式由 v5 升至 v6。v1–v5、`.jiajian`、`.sdworkbench` 及旧草稿打开后沿用原混音，用户可在本工程启用新设置。首次覆盖旧文件前保留可独立打开的 `pre-v6` 备份。新工程保存重开后恢复混音参数。

**验收。** 用合成口播和恒幅配乐，对照关闭闪避的结果，口播稳定段配乐 RMS 降幅与设定差 ≤0.5 dB，恢复时长误差 ≤10 ms。用两端电平相反的低频测试曲检查每个接缝，相邻样本差 ≤0.02（满幅为 1）。在 T12 音频回归中对照同一组合的试听与导出，检查选曲、闪避和接缝位置。批量导出两条原始响度不同的组合，逐文件复测目标 ±1 LU、真峰值 ≤−1 dBTP。另查封面、静音、短曲与旧草稿重开。
