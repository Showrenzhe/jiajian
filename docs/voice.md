# 口播与配音设置

## 录音放在哪条轨

口播指时间线上的人声音轨。「配音」指从脚本生成语音的操作。已经录好的声音可以直接导入，批量生成语音需要先配置服务。

分段式在画面轨下方显示独立的分段口播轨。两条轨道按分镜对齐并共用横向滚动条。点对应分镜的「新增口播轨」可导入本地音频。「同轨号匹配」在每条成片中选用各分镜的同号口播，缺少该轨时该分镜无口播。「分镜内随机」在各组分镜内独立抽取，未加口播的分镜保持无口播。调整分镜顺序时，口播随对应画面移动。

整段和分段的已导入口播都可点「试听／字幕」播放原音频。在弹窗中可填写台词，或采用已关联脚本预填的台词，然后点「应用台词字幕」。字幕覆盖该口播在成片中实际保留的播放区间。整段轨同时有手动导入的 SRT 时，优先使用 SRT。

## 决定画面和口播的长度

「画面优先」保留画面时长，裁掉超出的口播。「口播优先」保留对白原速，分段式会裁短相邻口播首尾检测到的静音，并同步调整字幕。画面短时优先补用同分镜的其他候选，素材用完后复用同组素材。画面超出时按统一比例加速对齐，分段式逐组计算，整段式统一计算。

需要语速自然并保留完整台词时，可从「口播优先」配合「佳剪规则」开始预览。教程规则会裁长画面、慢放短画面。

## 云端配音

新安装默认使用 Breeze Blue 的 `breeze-tts-2-multilingual`。在 Breeze Blue 开发者控制台创建 API Key，复制创建时显示一次的 `brz_` 开头的完整密钥，粘贴到佳剪顶部「设置」的 Breeze Blue API Key 栏。`key_` 开头的是管理编号。保存后到「口播 → 生成全部口播」浏览、试听和选择音色。统一设置语速、音量和固定或随机音色，生成后点「使用配音」加入口播轨。也可在设置中选择 Seed Audio 或通用接口。

参数和服务字段见[云端配音接口](api/云端配音接口.md)。
