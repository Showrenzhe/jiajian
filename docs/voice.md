# 口播与配音设置

## 录音放在哪条轨

口播指时间线上的人声音轨。「配音」指从脚本生成语音的操作。已经录好的声音可以直接导入，批量生成语音需要先配置服务。

分段式在画面轨下方显示独立的分段口播轨。两条轨道按分镜对齐并共用横向滚动条。点对应分镜的「新增口播轨」可导入本地音频。「同轨号匹配」在每条成片中选用各分镜的同号口播，缺少该轨时该分镜无口播。「分镜内随机」在各组分镜内独立抽取，未加口播的分镜保持无口播。调整分镜顺序时，口播随对应画面移动。

整段和分段的已导入口播都可点「试听／字幕」播放原音频。在弹窗中可填写台词，或采用已关联脚本预填的台词，然后点「应用台词字幕」。字幕覆盖该口播在成片中实际保留的播放区间。整段轨同时有手动导入的 SRT 时，优先使用 SRT。

## 决定画面和口播的长度

在「口播」的「成片设置」选择对齐方式，展开「口播裁剪」可调整当前工程的参数。

**选「画面优先」时，画面决定口播最多能播多久。** 分段口播以所属分镜末尾为限，整段口播以成片末尾为限。新工程会在截止前最后半秒内按以下顺序选断点。

1. 有关联的 SRT 或带时间戳的识别字幕时，先找窗口内最近的一处句末。只有纯文本台词时，直接查找停顿。
2. 找到实测静音时，优先从停顿中间收声。提前收声后，余下的画面照常播放。
3. 两种断点都找不到时，口播播到截止处，末尾默认淡出 100 ms。保留的口播短于淡出时长时，淡出覆盖这段口播。

**选「口播优先」和「佳剪」规则时，相邻两段口播会裁短接缝静音。** 每侧默认保留 120 ms 气口。两侧之间有无口播的分镜时，会保留该边界。画面不足时先补用同分镜的其他候选，素材用尽后再复用。画面超出时按统一比例加速，分段式逐组计算，整段式统一计算。「教程」规则会裁长画面、慢放短画面。

| 智能裁剪参数 | 默认值 | 可调范围 |
| --- | --- | --- |
| 静音阈值 | −40 dB | −65 至 −15 dB |
| 最短静音 | 120 ms | 100–5000 ms |
| 接缝保留（每侧） | 120 ms | 0–500 ms |
| 硬切淡出 | 100 ms | 80–150 ms |

将鼠标移到标有「已裁短」的口播片段上，或用键盘聚焦片段，可查看开头、结尾各裁掉多少秒。标记按当前倍速下的播放时间计算。关联的口播字幕和包装随声音裁剪，独立贴在时间线上的字幕保留原位置。

打开旧工程或草稿时，「裁剪方式」默认为「沿用旧规则」，超长口播在截止处直接收声，相邻分段口播的接缝每侧保留 25 ms。要启用上述参数，可在这个工程里选择「智能裁剪」并保存。

## 云端配音

新安装默认使用 Breeze Blue 的 `breeze-tts-2-multilingual`。在 Breeze Blue 开发者控制台创建 API Key，复制创建时显示一次的 `brz_` 开头的完整密钥，粘贴到佳剪顶部「设置」的 Breeze Blue API Key 栏。`key_` 开头的是管理编号。保存后到「口播 → 生成全部口播」浏览、试听和选择音色。统一设置语速、音量和固定或随机音色，生成后点「使用配音」加入口播轨。也可在设置中选择 Seed Audio 或通用接口。

参数和服务字段见[云端配音接口](api/云端配音接口.md)。
