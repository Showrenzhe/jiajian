# T18 口播裁剪断点与静音参数（待确认）

## 现状

画面优先时，整段和分段口播都在可用时长末端硬切。口播优先的「佳剪」规则只裁相邻分段口播的接缝，静音阈值为 −40 dB，最短静音 120 ms，接缝两侧各留 25 ms。[口播渲染](../src/media.cjs) · [接缝计算](../src/ui/voice-alignment.js)

## 拟议交互与规则

画面优先时，整段口播以成片末尾为限，分段口播以所属分镜末尾为限。超长时，在截止点前最后 500 ms 内先取最近的、有字幕时间戳支持的句末，再找实测短停顿。候选断点必须落在已选音频内且留有可播放内容。找不到时就在截止点硬切，仅让口播末尾淡出，默认 100 ms，可调 80–150 ms，最长为实际保留时长。提前收声后，该轨以静音补足画面时长。

在「混剪设置 → 口播 → 成片设置」中调整工程参数。新工程默认阈值 −40 dB、最短静音 120 ms，接缝两侧各保留 120 ms。静音短于余量时保留原声。裁短的口播块显示标记，悬停或键盘聚焦可读出「裁掉开头 X 秒 / 结尾 Y 秒」。

## 工程兼容

v5 保存策略和参数。v1–v4 默认沿用旧算法，接缝各留 25 ms，硬切无淡出。首次覆盖保存前备份原件，用户主动启用后应用新策略。每段按手动裁剪顺序、倍速与偏移计算源区间到时间线的映射，手动裁剪点始终保留原值。[工程迁移](../src/project-format.cjs)

## 风险与验证

实时预览、生成预览和导出共用同一映射。随口播绑定的字幕和包装按保留区间重排，固定时间线字幕保留原位。单测覆盖跨断点字幕、重排、倍速、偏移及全静音，逐行断言关联字幕位于对应音频内。用可辨认音调验证自然断点、80/100/150 ms 淡出及画面时长，并比较三种播放结果和旧工程保存重开结果。[实时预览](../src/ui/draft-transport.js) · [生成预览](../src/preview-plans.cjs)
