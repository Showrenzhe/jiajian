# Windows 前台交互基线

2026-11-24 在同一台 Windows 10.0.26200 工作站上，用 Electron 45.2.3 的可见窗口采样。CPU 为 Intel Core i7-12700KF，Windows 显示设备为 GeForce RTX 4060 和 RTX 3060，驱动版本 32.0.16.1742。屏幕为 60 Hz，缩放 100%，应用窗口 1400 × 900，Electron 报告 GPU 合成已启用。系统报告 RTX 4060 输出 60 Hz。集成显卡仍待另机采样。

## 1,000 项批量预览

`npm run bench:large` 用 5 个分镜生成 1,000 条组合。首次生成仍使用默认的重复度筛选。驱动确认此时显示少于 1,000 项，再从原生选择器切到「全部重复度」。首绘从可信的 `change` 事件计时，直到状态栏显示 1,000 项、首个可见窗口已挂载，并经过一次渲染机会。`environment.batchReadyMs` 单独记录从点击「生成预览」到组合就绪的耗时。

连续滚动使用真实滚轮。报告的 `results.batchScroll.p95Ms` 来自滚动期间渲染器的帧间隔。候选 P95 超过 25.05 ms 时验收失败，正好 25.05 ms 可以通过。托管配对运行按同侧两轮的全部帧间隔计算 P95，原有的相对回归检查同时生效。

筛选使用 Chromium 的文本输入，从完整列表分别搜索第 123、321、555、777、999 条。每次计时从可信的 `input` 事件开始，到状态栏和唯一挂载行都匹配目标为止。JSON 的 `batchPreview.firstRenderMs` 和 `batchPreview.filterInputMs` 保留首绘与五次输入的实测值。比较脚本报告两侧的首绘均值、筛选 P95 和差值。这两项计时没有绝对时限。旧版 JSON 可继续比较已有场景，新指标以实际采集到的版本为准。

### T9 同机实测

在上述 60 Hz Windows 工作站分别运行一次大工程基准。T8 基线为 `44a566f`，T9 包含列表滚动定位修复。两次均使用 Electron 45.2.3、1400 × 900 的前台窗口、100% 缩放和 GPU 合成，同一份采样驱动的 SHA-256 以 `d5ea5209` 开头。

## 核对托管 CI 的配对报告

在 Actions 中打开对应提交的 CI，下载 `benchmark-large`。归档里按执行顺序包含 `base-1.json`、`head-1.json`、`head-2.json`、`base-2.json`。四轮使用同一台机器、同一套测试驱动，每轮都重新启动佳剪。PR 的 `base` 是目标分支在事件中的提交，`head` 是 GitHub 为此次检查生成的合并提交。

- 先看 `summary.json`。六个场景分别汇总每个版本两轮的原始帧间隔，再取第 95 百分位。每个版本、每个场景至少要有 100 个间隔。`invalid` 表示样本、操作记录或环境不满足比较条件，具体原因在 `errors` 中。任一场景的 P95 同时增加超过 20% 和 2 ms，或 1,000 项列表的候选滚动 P95 超过 25.05 ms，都会触发 `regression`，详情在 `regressions` 中。
- 查看单轮 JSON 中相应场景的 `frameIntervalsMs`、`trustedEvents` 和 `actions`，可核对原始帧间隔、窗口收到的真实输入和驱动发出的操作。每轮的同名 `.log` 保留运行输出。缺少报告时，可从对应日志或作业失败步骤检查原因。
- `revisions.txt` 记录基线和候选提交。`provenance.json` 记录实际检出的源码树，以及采样驱动、依赖锁、FFmpeg 和 FFprobe 的哈希。下载的归档可用 `node scripts/compare-bench.cjs --paired 解压目录` 重新汇总。

## 集显采样

内部 Windows 集显采样默认关闭。公开仓库中的外部贡献可能改动工作流，使自托管 Runner 在内部机器上执行不受信任的代码。建议仓库公开期间保持关闭，等仓库转为私有后再启用。

启用时，由仓库管理员登记带有 `self-hosted`、`Windows`、`integrated-graphics` 标签的内部集显机器，并将仓库 Actions 变量 `INTERNAL_RUNNER_ENABLED` 设为 `true`。随后在 Actions 的 CI 工作流中选择默认分支，勾选集显采样并手动运行。完成后下载 `benchmark-integrated-graphics` 查看报告。

要验证默认关闭状态，可在变量未设置时按上述方式手动运行一次。预期 `integrated-graphics` 显示为已跳过（Skipped），无需登记机器。
