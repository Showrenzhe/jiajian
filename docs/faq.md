# 常见问题

### 为什么预览画面上只有音频文件名？

这是播放头落在只有口播或配乐的区间时，播放器使用的提示。先对照出问题的变体与时间码，检查相邻分镜的画面是否连续、视频轨是否可见，或素材是否被标记为缺失。也可用「播放预览」核对已选成片组合。进一步定位导出故障时，请保留异常 MP4、相邻正常变体、工程以及对应时间码。

### 没有独立显卡，怎样编辑和导出？

混剪使用 FFmpeg 的 CPU 编码。若剪辑台闪烁、黑屏或频繁崩溃，在设置打开「兼容模式（软件渲染）」后重启。该选项控制桌面绘制。记录问题时请标明是编辑器预览出现异常，还是导出的 MP4 在其他播放器里也能看到。

### 旧草稿提示速度无效，或者原素材换了位置？

在新版打开旧草稿或工程。如果提示缺失，选定素材当前所在的目录重新匹配。需要回到旧机器工作时，保留升级前的副本。[迁移指南](migration.md)

### 如何向维护人员提供信息？

从设置导出诊断包，记录佳剪版本、Windows 版本、操作步骤和出错时间。视频异常应同时注明第几条变体、出现在哪个分镜、重放同一文件时是否仍在同一处出现。诊断附件通过团队内部渠道提供。
