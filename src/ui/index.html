                          口播选项说明与推荐设置

                          以口播为主的成片推荐使用口播优先、佳剪规则。分段模式按同轨号匹配。

                          整段口播
                          ① ━━━ ③ 一条录音贯穿整片。
                          分段口播
                          ① ▏② ▏③ 每组分镜单独放置口播。
                          画面优先
                          画面 → 声音 保留完整画面，裁掉超出的口播。
                          口播优先
                          声音 → 画面 保持口播原速，让画面对齐台词。
                          佳剪规则
                          A + B → 对齐 画面短时补候选，长时均匀加速。
                          教程规则
                          A → 对齐 裁短较长画面，慢放较短画面。
                          同轨号匹配
                          ①A · ②A 每个分镜使用同一轨号的口播。
                          分镜内随机
                          ①B · ②A 每个分镜独立抽取一条已添加的口播。
